# Чек-лист ручного тестирования eCorgi

Автотесты покрывают физику, автомат состояний и спрайты. Всё, что связано с
живым окном и мышью, проверяется руками.

## Окно и Z-order
- [ ] Корги виден поверх обычных окон и не мигает при их переключении
- [ ] Клик по прозрачной области рядом с корги проходит в окно под ним
- [ ] Клик по самому корги не забирает фокус у активного приложения
- [ ] Корги виден на всех Spaces, не ломается при Mission Control
- [ ] Полноэкранное приложение: корги либо поверх, либо корректно скрыт

## Поведение
- [ ] Ходит по нижнему краю экрана, разворачивается у краёв
- [ ] Садится, засыпает после долгого простоя, просыпается
- [ ] Убегает при подведении курсора, успокаивается на расстоянии
- [ ] Перетаскивается мышью, при отпускании падает и приземляется
- [ ] Забравшись на верх окна, стоит на нём; при закрытии окна — падает
- [ ] Переносится к курсору по пункту меню «Позвать корги»

## Лазание и подвес
- [ ] Иногда идёт целенаправленно к боковой грани окна, а не бродит случайно
- [ ] Залезает по боковой грани наверх и переступает на верхний край окна
- [ ] У грани окна во весь экран лезет по внутренней стороне и не уползает за экран
- [ ] Дойдя до конца верхней грани, иногда свешивается и покачивается
- [ ] С подвеса либо подтягивается обратно, либо разжимает лапы и падает
- [ ] Подтянувшись, отходит от края и не залипает в цикле «повис — подтянулся»
- [ ] Окно закрыли или передвинули во время лазания/подвеса — питомец падает, а не зависает в воздухе
- [ ] Окно передвинули под ним — не остаётся стоять на пустом месте дольше секунды

## Прыжки
- [ ] Иногда подскакивает на месте, приземляясь туда же
- [ ] Набегавшись (больше половины порога усталости), подскакивать перестаёт
- [ ] С края окна спрыгивает наружу по дуге, а не падает вертикально
- [ ] Если под траекторией есть другое окно — приземляется на него
- [ ] У окна во всю ширину не пытается прыгнуть за край экрана, а разворачивается

## Опоры соответствуют видимым окнам
- [ ] Корги не ходит по воздуху: под ним всегда видимый край окна или низ экрана
- [ ] Окно, развёрнутое во весь экран позади остальных, опорой не служит
- [ ] Не карабкается по пустому боковому краю дисплея
- [ ] Если все окна закрыты или свёрнуты — живёт только внизу экрана
- [ ] Забравшись на окно, через ~30 секунд сам спускается вниз
- [ ] `ECORGI_DEBUG=2` печатает список окон и полок, совпадающий с тем, что на экране

## Сон по усталости
- [ ] После ~2 минут беготни корги укладывается спать сам
- [ ] Долгое сидение на месте усталость не копит (спит только «от скуки»)
- [ ] Не засыпает посреди грани окна, в полёте и когда его тащат мышью
- [ ] Проснувшись, снова набирает усталость с нуля
- [ ] Перед сном укладывается, после сна поднимается — сон не наступает рывком
- [ ] Пункт меню «Уложить спать» / «Разбудить» тоже идёт через эти переходы
- [ ] Курсор рядом или перетаскивание будят сразу, без потягиваний
- [ ] Спящего и укладывающегося курсор не будит — мимо мыши он спит спокойно
- [ ] Спящего можно поднять, взяв мышью, и пунктом меню «Разбудить»

## Настройки
- [ ] Ползунки скорости и размера применяются сразу
- [ ] «Убегать от курсора» и «Ходить по краям окон» реально выключают поведение
- [ ] Автозапуск при входе включается и переживает перезагрузку
- [ ] После закрытия окна настроек иконка в Dock снова исчезает

## Мультимонитор
- [ ] Корги корректно ходит по нижнему краю второго экрана
- [ ] Экраны разной высоты и масштаба: позиция не съезжает
- [ ] Отключение монитора, на котором стоял корги, не роняет приложение

## Производительность
- [ ] В простое (сон/сидит) — до ~1–2% CPU в Activity Monitor
- [ ] При ходьбе — до ~3–4% CPU
- [ ] Нет роста памяти за час работы
- [ ] Instruments → Energy Log: приложение не в «высоком» потреблении
