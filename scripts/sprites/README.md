# Инструменты для спрайтов

Скрипты запускаются напрямую: `swift <файл> <аргументы>`.

## split-sheet.swift

Разбирает спрайт-лист на кадры и вписывает их в холст пака.

```bash
swift scripts/sprites/split-sheet.swift <лист.png> <куда> <действие> <ширина> <высота> <рост>
# пример: лист бега -> 19 кадров run_NN.png на холсте 102x104, рост 70
swift scripts/sprites/split-sheet.swift sheet.png /tmp/out run 102 104 70
```

Кадры вырезаются по связным областям, а не по равным долям ширины: доли
обычно не сходятся нацело, а соседние кадры на листе соприкасаются, и обрезка
прямоугольником захватила бы кусок соседа.

Линия земли берётся по самой нижней точке цикла, отступы от неё сохраняются —
покачивание не теряется. По горизонтали кадры центрируются.

Скрипт печатает число найденных кадров: если оно не совпало с ожидаемым,
лист не годится (кадры слиплись или в них есть оторванные детали).

## contact-sheet.swift

Собирает все кадры действия в один лист с номерами и линией земли —
чтобы проверить разбор глазами.

```bash
swift scripts/sprites/contact-sheet.swift Sources/eCorgiKit/Resources/Sprites run /tmp/run.png
```
